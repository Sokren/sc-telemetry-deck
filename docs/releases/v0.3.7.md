**EN — SC Telemetry Deck 0.3.7** — flight, boost, shields and hull on the Stream Deck, and a "My ship" card in the web app (checked in flight on the Arrow and the Lightning F8C, Star Citizen 5.0 PTU).

🎬 Demo: https://youtu.be/t30sASa_oD4

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — Stream Deck (Ship Display)**
- **Ship**: manufacturer, model and flying / landed (e.g. "Anvil · Arrow · Flying").
- **Shields** and **hull** in % with a colored gauge — shields drain in NAV mode, hull turns orange then red after impacts.
- **Speed**, **vertical speed** ("+11" / "−16 m/s"), **radar altitude** ("—" when out of range, e.g. in space).
- **G-force** ("6.4 G", no color: the game only sends the recorded peak, not your limit).
- **Boost reserve** in % — "Boost ▲" while engaged, red when the game flags it critical (below about 25 %).
- **Hydrogen** in %, "—" on ships that don't send it.

**New — web app**
- **My ship** card at the top of the *Ship* tab and in the views' *Add* menu (large or compact): model, manufacturer, flying / landed, mode, role, boost, shields, hull and the instruments your ship sends.
- **Vertical speed**, **G-force** and **Boost** instruments; ship model in the public API.
- **API contract 1.3.0** (additive): new instrument ids (decoys, noise, weapons, flight, boost), `shipStatus.model` and `boostEngaged`, `ship_card` view item.

**Fixed**
- Web app: radar altitude showed the game's "out of range" value (3.4e38) instead of "—".
- Web app: hydrogen and hull showed 0 % in red when the game does not send them; now "—".

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.7** — vol, boost, boucliers et coque sur le Stream Deck, et encart « Mon vaisseau » dans l'appli web (vérifié en vol sur l'Arrow et le Lightning F8C, Star Citizen 5.0 PTU).

🎬 Démo : https://youtu.be/t30sASa_oD4

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — Stream Deck (Ship Display)**
- **Vaisseau** : constructeur, modèle et en vol / posé (ex. « Anvil · Arrow · En vol »).
- **Boucliers** et **coque** en % avec une jauge colorée — les boucliers se vident en mode NAV, la coque passe en orange puis en rouge après des chocs.
- **Vitesse**, **vitesse verticale** (« +11 » / « −16 m/s »), **altitude radar** (« — » hors de portée, par exemple dans l'espace).
- **G subis** (« 6,4 G », sans couleur : le jeu n'envoie que le pic enregistré, pas ta limite).
- **Réserve de boost** en % — « Boost ▲ » quand il est engagé, rouge quand le jeu le signale critique (sous 25 % environ).
- **Hydrogène** en %, « — » sur les vaisseaux qui ne l'envoient pas.

**Nouveau — appli web**
- Encart **Mon vaisseau** en tête de l'onglet *Vaisseau* et dans le menu *Ajouter* des vues (grand ou compact) : modèle, constructeur, en vol / posé, mode, rôle, boost, boucliers, coque et les instruments que ton vaisseau envoie.
- Instruments **Vitesse verticale**, **Accélération (G)** et **Boost** ; modèle du vaisseau dans l'API publique.
- **Contrat d'API 1.3.0** (ajouts seulement) : nouveaux identifiants d'instruments (contre-mesures, armes, vol, boost), `shipStatus.model` et `boostEngaged`, case de vue `ship_card`.

**Corrigé**
- Appli web : l'altitude radar affichait la valeur « hors de portée » du jeu (3,4e38) au lieu de « — ».
- Appli web : l'hydrogène et la coque affichaient 0 % en rouge quand le jeu ne les envoie pas ; maintenant « — ».

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
