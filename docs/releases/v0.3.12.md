**EN — SC Telemetry Deck 0.3.12** — Save and share your web app views: export them as a file or a code to paste on Discord, and import the ones your friends share.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **⇪ Export / 📥 Import** in your views (open the padlock, the buttons are next to the view name):
  - export **this view** or **all your views** (handy for a backup);
  - as a **`.json` file** (named after the view, with the date) or as a **code to copy and paste** (`SCTD1:…`) — paste it on Discord, Reddit or anywhere;
  - to import, paste a code or drop a `.json` file: a **preview** shows the view, its sections and items, and **which version exported it**;
  - a view made with a newer version still imports: the items your version cannot read are **left out and listed with the reason** ("Update to get everything");
  - imported views are **added** to yours (10 views at most), nothing is replaced.
- **API contract 1.9.0** (additive): `GET /api/v1/views/export` (`?id=` for one view, `&as=code` for the code), `POST /api/v1/views/import` (a file or `{ "code": "SCTD1:…" }`; `?dry_run=1` for the preview only). The answer gives the views created, `from_version` and the `skipped` items with their reason.

**Docs**
- READMEs brought up to date with versions 0.3.8 to 0.3.11 (sensitive actions, Flight ready, web app on Linux under Wine…).

The Stream Deck plugin is unchanged (version number only).

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.12** — Sauvegarde et partage tes vues de l'appli web : exporte-les en fichier ou en code à coller sur Discord, et importe celles de tes amis.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — appli web**
- **⇪ Exporter / 📥 Importer** dans tes vues (ouvre le cadenas, les boutons sont à côté du nom de la vue) :
  - exporte **cette vue** ou **toutes tes vues** (pratique pour une sauvegarde) ;
  - en **fichier `.json`** (au nom de la vue, avec la date) ou en **code à copier-coller** (`SCTD1:…`) — à coller sur Discord, Reddit ou ailleurs ;
  - pour importer, colle un code ou dépose un fichier `.json` : un **aperçu** montre la vue, ses sections et ses cases, et **la version qui l'a exportée** ;
  - une vue faite avec une version plus récente s'importe quand même : les cases que ta version ne sait pas lire sont **laissées de côté et listées avec la raison** (« Mets à jour pour tout récupérer ») ;
  - les vues importées **s'ajoutent** aux tiennes (10 vues au plus), rien n'est remplacé.
- **Contrat d'API 1.9.0** (ajouts seulement) : `GET /api/v1/views/export` (`?id=` pour une vue, `&as=code` pour le code), `POST /api/v1/views/import` (un fichier ou `{ "code": "SCTD1:…" }` ; `?dry_run=1` pour l'aperçu seulement). La réponse donne les vues créées, `from_version` et les cases ignorées (`skipped`) avec leur raison.

**Docs**
- READMEs à jour des versions 0.3.8 à 0.3.11 (actions sensibles, Prêt au vol, appli web sous Linux avec Wine…).

Le plugin Stream Deck ne change pas (numéro de version seulement).

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
