**EN — SC Telemetry Deck 0.3.13** — Make your web app views look like a ship HUD: rings, arcs and gauges, your own names, item widths in slots — plus a portable version for PCs where Windows blocks the exe.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **Customize a view** (open the padlock):
  - **Look** next to the view name: *Standard* or **Ship HUD** — cockpit-screen frames, monospaced figures, in the colors of your theme (Green cockpit, Amber…).
  - a **⚙** button on each item:
    - a **display name** of your choice — any language, emojis (🍖, 💧, 🛬…); only your view changes, the API and the Stream Deck keep the game names;
    - a **style** for gauges: card, **ring**, **arc**, bar, vertical bar, segments, vertical segments or big number (values without a maximum, like speed: card or number);
    - for the **balance**, the **scale**: auto (15.0M), thousands (15,021k), millions (15.02M) or every digit (15,021,736).
  - **Width in slots** with the “2 → 3” button: 8 slots per row in a full-width section, 4 in a half section or on a phone. In edit mode, an item's buttons now sit above it instead of covering it.
  - Your existing views keep their layout.
- **⚙ Options**:
  - **Number format** (per device): same as the language, **1 234,5** or **1,234.5** — e.g. an English HUD with French-style numbers;
  - **Language**: one button per language (Français / English).
- **Portable version** `sc-telemetry-web-0.3.13-portable.zip`: for PCs where **Windows Smart App Control** blocks `sc-telemetry-web.exe` (a "potentially dangerous app" box with only *OK*). Same app, started with the official, signed `node.exe`. Right-click the zip → *Properties* → tick **Unblock**, extract it, double-click `SC Telemetry Web.cmd` (details in the `README.txt` inside).
- **API contract 1.10.0** (additive): `look` on a view; `label`, `display` (`style`, `length`) and widths 0.5 to 4 (`size`) on an item; `amount` (raw amount) on the balance.

**Changed — Stream Deck plugin and web app**
- **Percentages are truncated like in the game**: 98.87% shows **98%** (it showed 99%).

**Fixed**
- API docs: they still said dangerous actions were refused (wrong since 0.3.9); the unused `dangerous_action` refusal code is removed.

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck), `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in) and `sc-telemetry-web-0.3.13-portable.zip` (the same web app for PCs where Smart App Control blocks the exe).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.13** — Donne à tes vues de l'appli web l'allure d'un HUD de vaisseau : anneaux, arcs et jauges, tes propres noms, largeur des cases en emplacements — plus une version portable pour les PC où Windows bloque l'exe.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — appli web**
- **Personnaliser une vue** (ouvre le cadenas) :
  - **Habillage** à côté du nom de la vue : *Standard* ou **HUD vaisseau** — cadres d'écran de bord, chiffres à chasse fixe, aux couleurs de ton thème (Cockpit vert, Ambre…).
  - un bouton **⚙** sur chaque case :
    - un **nom affiché** au choix — toute langue, emojis (🍖, 💧, 🛬…) ; seule ta vue change, l'API et le Stream Deck gardent les noms du jeu ;
    - un **style** pour les jauges : carte, **anneau**, **arc**, barre, barre verticale, segments, segments verticaux ou chiffre en gros (valeurs sans maximum, comme la vitesse : carte ou chiffre) ;
    - pour le **solde**, l'**échelle** : auto (15,0 M), milliers (15 021 k), millions (15,02 M) ou tous les chiffres (15 021 736).
  - **Largeur en emplacements** avec le bouton « 2 → 3 » : 8 par ligne dans une section pleine largeur, 4 dans une demi-section ou sur téléphone. En édition, les boutons d'une case sont maintenant au-dessus d'elle au lieu de la recouvrir.
  - Tes vues existantes gardent leur disposition.
- **⚙ Options** :
  - **Format des nombres** (par appareil) : selon la langue, **1 234,5** ou **1,234.5** — par exemple un HUD en anglais avec des nombres à la française ;
  - **Langue** : un bouton par langue (Français / English).
- **Version portable** `sc-telemetry-web-0.3.13-portable.zip` : pour les PC où **Windows Smart App Control** bloque `sc-telemetry-web.exe` (une fenêtre « application potentiellement dangereuse » avec seulement *OK*). Même appli, lancée avec le `node.exe` officiel, signé. Clic droit sur le zip → *Propriétés* → cocher **Débloquer**, extraire, double-cliquer sur `SC Telemetry Web.cmd` (détails dans le `README.txt` du zip).
- **Contrat d'API 1.10.0** (ajouts seulement) : `look` sur une vue ; `label`, `display` (`style`, `length`) et largeurs 0.5 à 4 (`size`) sur une case ; `amount` (montant brut) sur le solde.

**Modifié — plugin Stream Deck et appli web**
- **Les pourcentages sont tronqués comme dans le jeu** : 98,87 % s'affiche **98 %** (c'était 99 %).

**Corrigé**
- Doc de l'API : elle disait encore que les actions dangereuses étaient refusées (faux depuis la 0.3.9) ; le code de refus `dangerous_action`, inutilisé, est retiré.

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck), `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré) et `sc-telemetry-web-0.3.13-portable.zip` (la même appli web pour les PC où Smart App Control bloque l'exe).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
