**EN — SC Telemetry Deck 0.3.11** — Flight ready and a character summary in the web app, an actions log in Debug mode, and the app now tells you when a new version is out.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **Ship** tab:
  - a big **✈ Flight ready** button (`v_flightready` — a command only, the game sends no "ready" state);
  - a one-line **character summary** above the ship card: health, hunger, thirst, oxygen (coloured by level) and a breathable-air note. Hide it with ✕ or in ⚙ Options (per device).
- **Character** tab: an **Actions** row — star map, wipe visor, mobiGlas, flashlight.
- 🐞 **Debug** tab: an **actions sent** log in the right column (last 200: time, action, where it came from, character position, the game's answer in plain words, response time), with *Errors only*, *Copy*, *Clear* and *Enlarge*; included in the recording. A button showing ⚠ tells why when hovered. The automatic view switch is paused while you are in Debug.
- **Update check**: at start, then daily, the app reads the latest release on GitHub. When a newer one is out, a **⬆ x.y.z available** badge appears at the top, and ⚙ Options → *Updates* shows your version, **Check now** and **Open GitHub ↗**. Nothing is downloaded automatically and no data is sent; turn it off in ⚙ Options. *(The badge only appears from the next release on, since 0.3.10 and older don't have it.)*
- ⚙ Options window a bit wider; buttons and links aligned.
- **API contract 1.8.0** (additive): `actions` in `GET /api/v1/debug` and the recording, `DELETE /api/v1/debug/actions`; `GET` / `PUT /api/v1/update`, `POST /api/v1/update/check`.

**Changed — web app**
- No more references to the Stream Deck in the page and the API docs: the app stands on its own.

The Stream Deck plugin is unchanged (version number only).

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.11** — Prêt au vol et résumé du perso dans l'appli web, journal des actions dans le mode debug, et l'appli te prévient quand une nouvelle version sort.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — appli web**
- Onglet **Vaisseau** :
  - un gros bouton **✈ Prêt au vol** (`v_flightready` — simple commande, le jeu n'envoie pas d'état « prêt ») ;
  - un **résumé du perso** sur une ligne au-dessus de l'encart du vaisseau : santé, faim, soif, oxygène (couleur selon le niveau) et une note sur l'air respirable. Masquable avec ✕ ou dans ⚙ Options (par appareil).
- Onglet **Personnage** : une rangée **Actions** — carte stellaire, essuyer la visière, mobiGlas, torche.
- Onglet 🐞 **Debug** : journal des **actions envoyées** dans la colonne de droite (200 dernières : heure, action, d'où elle vient, position du perso, réponse du jeu en clair, temps de réponse), avec *Erreurs seulement*, *Copier*, *Vider* et *Agrandir* ; ajouté à l'enregistrement. Un bouton qui affiche ⚠ explique pourquoi au survol. Le changement de vue automatique est en pause tant que tu es dans Debug.
- **Vérification de version** : au démarrage puis chaque jour, l'appli lit la dernière version publiée sur GitHub. Si elle est plus récente, un badge **⬆ x.y.z disponible** apparaît en haut, et ⚙ Options → *Mises à jour* affiche ta version, **Vérifier maintenant** et **Ouvrir GitHub ↗**. Rien n'est téléchargé automatiquement, aucune donnée envoyée ; désactivable dans ⚙ Options. *(Le badge n'apparaîtra qu'à partir de la prochaine version, la 0.3.10 et les précédentes ne l'ont pas.)*
- Fenêtre ⚙ Options un peu plus large ; boutons et liens alignés.
- **Contrat d'API 1.8.0** (ajouts seulement) : `actions` dans `GET /api/v1/debug` et dans l'enregistrement, `DELETE /api/v1/debug/actions` ; `GET` / `PUT /api/v1/update`, `POST /api/v1/update/check`.

**Modifié — appli web**
- Plus aucune mention du Stream Deck dans la page et la doc de l'API : l'appli est autonome.

Le plugin Stream Deck ne change pas (numéro de version seulement).

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
