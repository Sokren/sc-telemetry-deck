**EN — SC Telemetry Deck 0.3.9** — Cruise control on your keys, sensitive actions with a hold-to-eject, a red warning when doors are open, and color themes for the web app.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — Stream Deck**
- **Cruise control** (Alt+C) in *Ship Toggle*, **read only**: shows ON / OFF; a press does nothing (the game has no command for it). The speed limiter value and the Corsair's wings are not sent by the game, so they are not shown.
- **Sensitive actions**: opening / unlocking doors and ports, self-destruct, emergency exit and turning main power off are now offered on the *Ship Action* key and sent in **one press** (they stay refused to the AI).
- **Eject must be held 1.5 s**: a red ring fills up with the time left; releasing earlier cancels.
- *Ship Toggle*: doors (close / open), door locks (lock / unlock) and main power (on / off) now work **both ways**.
- **Red warning only in a dangerous state** (doors open, locks open): red outline, ⚠ and the state in red — nothing when closed / locked. Untick *Warning* on the key to remove it.

**New — web app**
- The same cruise control, sensitive actions, hold-to-eject (grid tile, view item) and red warning (turn it off in ⚙ Options, per device).
- **Color themes**: Default, Green cockpit, Amber, Night blue and Light (day), plus an accent color — remembered per device.
- **⚙ Options** window: appearance, language, automatic view, tablet / phone access and help; the header is lighter.
- **❓ Enable telemetry** guide, shown while the game sends nothing: step by step for 5.0 (`user.cfg`) and 4.10.3, with *Copy* buttons. The app never touches the game's files.
- **API contract 1.6.0** (additive): `cruise` function, `readOnly`, `danger` on ship functions, `hold` on grid tiles.

**Fixed**
- Web app: the header buttons overflowed the screen on phones; they now wrap.

**Known limitation**: in 5.0 PTU the game does **not send the door state yet** and **refuses the door / lock / port commands** through the API (your in-game keys still work) — tested on the Avenger Titan and the Corsair. The *Doors* and *Door locks* keys show "—" until CIG wires them; nothing to change on your side when it happens.

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.9** — la croisière sur tes touches, les actions sensibles avec éjection maintenue, une alerte rouge quand les portes sont ouvertes, et des thèmes de couleurs pour l'appli web.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — Stream Deck**
- **Croisière** (Alt+C) dans *Ship Toggle*, **en lecture seule** : affiche ON / OFF ; un appui ne fait rien (le jeu n'a aucune commande pour elle). La valeur du limiteur de vitesse et les ailes du Corsair ne sont pas envoyées par le jeu, donc pas affichées.
- **Actions sensibles** : ouvrir / déverrouiller portes et sas, autodestruction, sortie d'urgence et coupure de la puissance générale sont maintenant proposées sur la touche *Ship Action* et envoyées en **un appui** (toujours refusées à l'IA).
- **L'éjection demande de rester appuyé 1,5 s** : un anneau rouge se remplit avec le temps restant ; relâcher avant annule.
- *Ship Toggle* : portes (fermer / ouvrir), verrous (verrouiller / déverrouiller) et puissance générale (allumer / couper) marchent **dans les deux sens**.
- **Alerte rouge seulement en état dangereux** (portes ouvertes, verrous ouverts) : contour rouge, ⚠ et état en rouge — rien quand c'est fermé / verrouillé. Décoche *Alerte* sur la touche pour l'enlever.

**Nouveau — appli web**
- Les mêmes croisière, actions sensibles, éjection maintenue (tuile de la grille, case des vues) et alerte rouge (désactivable dans ⚙ Options, par appareil).
- **Thèmes de couleurs** : Actuel, Cockpit vert, Ambre, Bleu nuit et Clair (jour), plus une couleur d'accent — retenus par appareil.
- Fenêtre **⚙ Options** : apparence, langue, vue automatique, accès tablette / téléphone et aide ; la barre du haut est allégée.
- Tuto **❓ Activer la télémétrie**, affiché tant que le jeu n'envoie rien : pas à pas pour la 5.0 (`user.cfg`) et la 4.10.3, avec boutons *Copier*. L'appli ne touche jamais aux fichiers du jeu.
- **Contrat d'API 1.6.0** (ajouts seulement) : fonction `cruise`, `readOnly`, `danger` sur les fonctions vaisseau, `hold` sur les tuiles de la grille.

**Corrigé**
- Appli web : sur téléphone, les boutons du haut débordaient de l'écran ; ils passent maintenant à la ligne.

**Limite connue** : en 5.0 PTU, le jeu **n'envoie pas encore l'état des portes** et **refuse les commandes portes / verrous / sas** via l'API (tes touches du jeu marchent) — testé sur l'Avenger Titan et le Corsair. Les touches *Portes* et *Verrous* affichent « — » jusqu'à ce que CIG les branche ; rien à changer de ton côté ce jour-là.

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
