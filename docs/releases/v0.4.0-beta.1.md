**EN — SC Telemetry Deck 0.4.0-beta.1 (pre-release)** — Plugins, external access tokens, an admin token for the PC and a mobile token for tablets and phones, the Instrument panel tab, a full screen button and the new game data of 5.0 PTU.

> ⚠️ **Pre-release: not everything is tested yet.** The latest 5.0 PTU builds (13273298 and later) do not open the game's local telemetry API, so the new game data, the plugins, the external access and the mobile token could not be tested in game. Testing resumes as soon as telemetry comes back on the 5.0 PTU. Use this version to try things out, and keep 0.3.15 if you need something stable.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

The update check of 0.3.15 and later does not offer this pre-release: download it from this page.

**New — web app**
- **🧭 Instrument panel** tab: a built-in view for a tablet next to the keyboard (quantum travel as a ring, notched gauges, functions, tracked mission, performance). The *Instrument panel* template (＋ New view) turns it into a view of your own, and the *Instrument panel* look works on every view. Opens directly from the QR code (`?view=instrument`).
- **⛶ Full screen** button in the top bar (tablet, Android phone, PC). Hidden where the browser does not allow it (iPhone).
- **Plugins**: the app starts separate programs from the `plugins` folder next to the app (Node, Python or `.exe`), each with its own short-lived token and the level you grant: Read, Pilot or Full pilot. A new or changed plugin never starts on its own: **⚙ Options → Plugins** shows the exact command, the files and their fingerprint before you enable it. Live log, stop, restart, disable. Example in `examples/plugins/`.
- **External access** (**⚙ Options → External access**): tokens for your tools (VoiceAttack, overlay, bot…) with a name and a level (Read, Pilot, Full pilot). Renew, stop for a while, revoke, and see their live log.
- **New game data of 5.0 PTU (build 13273298)**, shown when the game sends it: game state, quantum travel card, player name, mode, location, armistice zone, CrimeStat, tracked mission, performance (FPS, ping…). Also available as **My view** items, and a view can open automatically by the character's mode.

**Security**
- **Admin token and mobile token**: the app's token becomes the **admin token** and works only on the PC. Tablets and phones share a **mobile token**, given by the QR code, without the settings (local network, external tokens, plugins, updates). **New token** replaces only the mobile token: the PC stays connected.
- ⚠️ **Tablets and phones already connected must scan the QR code once** after the update. They show a message saying so.
- The app refuses requests whose `Host` header is neither `localhost` nor an IP address (DNS rebinding protection).

**Changed**
- Update check: only main versions (`x.y.z`) are offered. Pre-releases, betas and release candidates are ignored.
- Game schema: 5.0 PTU build 13273298 (5.0.202.35026).

**Stream Deck plugin**: **Ship Display** shows quantum travel (time left, destination, distance, calibration); **Actor Display** shows mode, location, CrimeStat, armistice zone, mission, FPS and ping — when the game sends them.

**API**: contract **1.13.0** — `GET /api/v1/game`, `/api/v1/access/tokens`, `/api/v1/plugins`, new fields in `/api/v1/character` and `/api/v1/ship/status`, 403 `pc_only` and `bad_host`. See `docs/api/`.

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck), `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in) and `sc-telemetry-web-0.4.0-beta.1-portable.zip` (the same web app for PCs where Smart App Control blocks the exe).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.4.0-beta.1 (préversion)** — Plugins, jetons d'accès externes, un jeton admin pour le PC et un jeton mobile pour les tablettes et téléphones, l'onglet Instrument de bord, un bouton plein écran et les nouvelles données du jeu en 5.0 PTU.

> ⚠️ **Préversion : tout n'est pas encore testé.** Les derniers builds 5.0 PTU (13273298 et suivants) n'ouvrent pas l'API de télémétrie locale du jeu : les nouvelles données du jeu, les plugins, les accès externes et le jeton mobile n'ont donc pas pu être testés en jeu. Les tests reprendront dès le retour de la télémétrie sur la 5.0 PTU. Utilise cette version pour essayer, et garde la 0.3.15 si tu as besoin de stabilité.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

La vérification de version de la 0.3.15 et suivantes ne propose pas cette préversion : télécharge-la depuis cette page.

**Nouveau — appli web**
- Onglet **🧭 Instrument de bord** : vue intégrée pour une tablette posée à côté du clavier (saut quantique en anneau, jauges à crans, fonctions, mission suivie, performances). Le modèle *Instrument de bord* (＋ Nouvelle vue) en fait une vue à toi, et l'habillage *Instrument de bord* marche sur toutes les vues. S'ouvre directement depuis le QR code (`?view=instrument`).
- Bouton **⛶ Plein écran** dans la barre du haut (tablette, téléphone Android, PC). Caché quand le navigateur ne le permet pas (iPhone).
- **Plugins** : l'appli lance des programmes séparés depuis le dossier `plugins` à côté de l'appli (Node, Python ou `.exe`), chacun avec son propre jeton de courte durée et le niveau que tu accordes : Lecture, Pilotage ou Pilotage complet. Un plugin nouveau ou modifié ne démarre jamais seul : **⚙ Options → Plugins** montre la commande exacte, les fichiers et leur empreinte avant que tu l'actives. Journal en direct, arrêter, relancer, désactiver. Exemple dans `examples/plugins/`.
- **Accès externes** (**⚙ Options → Accès externes**) : des jetons pour tes outils (VoiceAttack, overlay, bot…) avec un nom et un niveau (Lecture, Pilotage, Pilotage complet). Renouveler, mettre en pause, révoquer, et voir leur journal en direct.
- **Nouvelles données du jeu 5.0 PTU (build 13273298)**, affichées quand le jeu les envoie : état du jeu, encart saut quantique, pseudo, mode, lieu, zone d'armistice, CrimeStat, mission suivie, performances (FPS, ping…). Aussi disponibles en **cases de Ma vue**, et une vue peut s'ouvrir toute seule selon le mode du perso.

**Sécurité**
- **Jeton admin et jeton mobile** : le jeton de l'appli devient le **jeton admin** et ne marche que sur le PC. Les tablettes et téléphones partagent un **jeton mobile**, donné par le QR code, sans les réglages (réseau local, jetons externes, plugins, mises à jour). **Nouveau jeton** ne remplace que le jeton mobile : le PC reste connecté.
- ⚠️ **Les tablettes et téléphones déjà connectés doivent rescanner le QR code une fois** après la mise à jour. Un message le leur indique.
- L'appli refuse les requêtes dont l'en-tête `Host` n'est ni `localhost` ni une adresse IP (protection contre le DNS rebinding).

**Changé**
- Vérification de version : seules les versions principales (`x.y.z`) sont proposées. Préversions, bêtas et versions candidates ignorées.
- Schéma du jeu : 5.0 PTU build 13273298 (5.0.202.35026).

**Plugin Stream Deck** : **Ship Display** affiche le saut quantique (temps restant, destination, distance, calibrage) ; **Actor Display** affiche le mode, le lieu, le CrimeStat, la zone d'armistice, la mission, les FPS et le ping — quand le jeu les envoie.

**API** : contrat **1.13.0** — `GET /api/v1/game`, `/api/v1/access/tokens`, `/api/v1/plugins`, nouveaux champs dans `/api/v1/character` et `/api/v1/ship/status`, 403 `pc_only` et `bad_host`. Voir `docs/api/`.

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck), `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré) et `sc-telemetry-web-0.4.0-beta.1-portable.zip` (la même appli web pour les PC où Smart App Control bloque l'exe).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
