**EN — SC Telemetry Deck 0.3.14** — One Ship Action for everything: commands and ship functions with their live state on the key, icons that change with the state, and your own key titles.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**⚠ Breaking change — Stream Deck plugin**
- **Ship Toggle is merged into Ship Action** and no longer appears in the Stream Deck action list. **Nothing to redo**: Ship Toggle keys already on your Stream Deck keep working. Their settings (function, mode, style, red warning) are converted automatically the first time they appear, and they now open the Ship Action panel. For a new key with a live state, pick **Ship Action** and choose the function (landing gear, lights, VTOL…).
- **Ship Action keys set to a function with a state look different**: they show the real state instead of a fixed icon. To get the old look back: *Image* → **No state (fixed icon)**.
- **A press takes the state into account**: "On" on a function that is already on no longer sends anything (✔). Outside a ship, or when the state is unknown, the command is sent as before.

**New — Stream Deck plugin**
- Ship Action: **live state on the key** for landing gear, lights, VTOL, decoupled, G-safe, cruise, ESP, advanced HUD, night vision, NAV / SCM mode, power, doors and locks. Styles A Text, B LED and C Filled, and a red warning when doors or locks are open.
- **The icon changes with the state** (lights with a glow, eye open or closed, padlock open or closed, door ajar, shield full or dashed…), with a short "pop" when it changes and an animation while moving (VTOL rotates, the others blink orange). The landing gear keeps its icon.
- **ESP** and **cruise** are in the list (display only: the game has no command for them; cruise is Alt+C in game).

**Fixed — Stream Deck plugin**
- **The title typed in the Stream Deck now shows** on Ship Action (function with a state), Actor Display and Ship Display, dials included. It replaces the default name ("Health", "Gear"…); empty title = default name. If "Show title" is ticked, only the Stream Deck title shows (no duplicate).

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck), `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in) and `sc-telemetry-web-0.3.14-portable.zip` (the same web app for PCs where Smart App Control blocks the exe).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.14** — Un seul Ship Action pour tout : commandes et fonctions du vaisseau avec leur état réel sur la touche, pictogrammes qui changent selon l'état, et tes propres titres de touche.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**⚠ Changement incompatible — plugin Stream Deck**
- **Ship Toggle est fusionné dans Ship Action** et n'apparaît plus dans la liste des actions du Stream Deck. **Rien à refaire** : les touches Ship Toggle déjà posées continuent de marcher. Leurs réglages (fonction, mode, style, alerte rouge) sont convertis automatiquement la première fois qu'elles s'affichent, et elles ouvrent maintenant le panneau de Ship Action. Pour une nouvelle touche avec état, prendre **Ship Action** et choisir la fonction (train, phares, VTOL…).
- **Les touches Ship Action d'une fonction avec état changent d'apparence** : elles affichent l'état réel au lieu d'une icône fixe. Pour retrouver l'ancien rendu : *Image* → **Sans état (icône fixe)**.
- **Un appui tient compte de l'état** : « Allumer » sur une fonction déjà allumée n'envoie plus rien (✔). Hors du vaisseau, ou si l'état est inconnu, la commande est envoyée comme avant.

**Nouveau — plugin Stream Deck**
- Ship Action : **état sur la touche** pour le train, les phares, le VTOL, le découplage, le G-safe, la croisière, l'ESP, le HUD avancé, la vision nocturne, le mode NAV / SCM, la puissance, les portes et les verrous. Styles A Texte, B Voyant et C Fond coloré, et alerte rouge quand les portes ou les verrous sont ouverts.
- **Le pictogramme change selon l'état** (phares avec halo, œil ouvert ou fermé, cadenas ouvert ou fermé, porte entrouverte, bouclier plein ou en pointillé…), avec un petit « pop » au changement et une animation pendant un mouvement (le VTOL pivote, les autres clignotent en orange). Le train garde son icône.
- **ESP** et **croisière** sont dans la liste (affichage seul : le jeu n'a pas de commande ; la croisière, c'est Alt+C en jeu).

**Corrigé — plugin Stream Deck**
- **Le titre saisi dans le Stream Deck s'affiche** sur Ship Action (fonction avec état), Actor Display et Ship Display, molettes comprises. Il remplace le nom par défaut (« Santé », « Train »…) ; titre vide = nom par défaut. Si l'option « Afficher le titre » est cochée, seul le titre du Stream Deck s'affiche (pas de doublon).

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck), `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré) et `sc-telemetry-web-0.3.14-portable.zip` (la même appli web pour les PC où Smart App Control bloque l'exe).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
