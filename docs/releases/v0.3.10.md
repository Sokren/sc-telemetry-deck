**EN — SC Telemetry Deck 0.3.10** — Debug mode in the web app: see everything the game sends, raw, and record it for a bug report.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **🐞 Debug mode** (⚙ Options → *Advanced*, per device): adds a **Debug** tab with **everything the game sends**, raw and read only.
  - Every section of the stream with its age (green = live, orange = stale, grey = never received), or **All** at once.
  - The full tree, merged with the game schema: fields the game **does not send** are shown in grey (to see what your ship really exposes). Zero values the game leaves out are shown with their **real value** in italics (e.g. lights off → `lights_enabled false`).
  - Filter, freeze, copy the JSON or a field's path; the last game events; frames per second; app and game schema versions.
  - **⏺ Record**: keeps every raw frame (up to 10 000, about 10 min) and downloads them as a `.json` file — attach it to a bug report.
  - Nothing is ever sent to the game from this tab.
- **API contract 1.7.0** (additive): `GET /api/v1/debug`, `POST` / `DELETE /api/v1/debug/recording`.

The Stream Deck plugin is unchanged (version number only).

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.10** — mode debug dans l'appli web : voir tout ce que le jeu envoie, brut, et l'enregistrer pour un rapport de bug.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — appli web**
- **🐞 Mode debug** (⚙ Options → *Avancé*, par appareil) : ajoute un onglet **Debug** avec **tout ce que le jeu envoie**, brut et en lecture seule.
  - Chaque section du flux avec son âge (vert = à jour, orange = périmée, gris = jamais reçue), ou **Tout** d'un coup.
  - L'arbre complet, fusionné avec le schéma du jeu : les champs que le jeu **n'envoie pas** sont en gris (pour voir ce que ton vaisseau expose vraiment). Les valeurs nulles que le jeu ne transmet pas sont affichées avec leur **vraie valeur** en italique (ex. phares éteints → `lights_enabled false`).
  - Filtrer, figer, copier le JSON ou le chemin d'un champ ; les derniers événements du jeu ; les trames par seconde ; les versions de l'appli et du schéma.
  - **⏺ Enregistrer** : garde chaque trame brute (jusqu'à 10 000, environ 10 min) et les télécharge en fichier `.json` — à joindre à un rapport de bug.
  - Rien n'est jamais envoyé au jeu depuis cet onglet.
- **Contrat d'API 1.7.0** (ajouts seulement) : `GET /api/v1/debug`, `POST` / `DELETE /api/v1/debug/recording`.

Le plugin Stream Deck ne change pas (numéro de version seulement).

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
