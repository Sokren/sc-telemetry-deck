**EN — SC Telemetry Deck 0.3.8** — Morse code with the ship's lights, Morse in your web views, and the letter being sent shown live.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions** (Morse needs 5.0).

**New — Stream Deck (Morse Code)**
- **Ship's lights**: the *Light* setting now offers the ship's lights as well as the flashlight. The lights are switched on / off explicitly (seated in a ship) and left off at the end. Existing keys keep the flashlight.
- **Current letter**: while sending, the key shows the letter and its code, the lit sign in bold (e.g. `S` / `●··`), `␣` between words and the round when the message repeats (`1/2`).

**New — web app**
- **Morse in your views** (*Add* → *Morse*):
  - *Morse message*: a saved message — text, flashlight or ship lights, dot length, repetitions, set with ✏️. Lit while it is being sent.
  - *Free Morse*: type a message on the spot, Enter or ▶ to send, flashlight ⇄ ship lights. The last text is kept on the device.
  - Pressing any Morse item during sending stops it.
- While sending, Morse items and the grid's Morse tile show the **current letter and its code**, the lit sign highlighted.
- **API contract 1.5.0** (additive): `light` in `POST /api/v1/morse`, `settings` on `morse` / `morse_free` view items, `morse {playing, text, light, progress}` in the `state` event.

**Changed**
- The GitHub repository is now **Sokren/sc-telemetry-deck** (old links redirect).

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck) and `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.8** — morse avec les phares du vaisseau, morse dans tes vues web, et la lettre en cours d'envoi affichée en direct.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions** (le morse demande la 5.0).

**Nouveau — Stream Deck (Morse Code)**
- **Phares du vaisseau** : le réglage *Lumière* propose les phares en plus de la torche. Les phares sont allumés / éteints explicitement (assis dans un vaisseau) et laissés éteints à la fin. Les touches existantes gardent la torche.
- **Lettre en cours** : pendant l'envoi, la touche affiche la lettre et son code, le signe allumé en gros (ex. `S` / `●··`), `␣` entre deux mots et le tour quand le message est répété (`1/2`).

**Nouveau — appli web**
- **Morse dans tes vues** (*Ajouter* → *Morse*) :
  - *Message morse* : un message enregistré — texte, torche ou phares, durée d'un point, répétitions, réglés avec ✏️. Allumée pendant l'envoi.
  - *Morse libre* : tape un message sur le moment, Entrée ou ▶ pour l'envoyer, torche ⇄ phares. Le dernier texte est gardé sur l'appareil.
  - Un appui sur une case morse pendant un envoi l'arrête.
- Pendant l'envoi, les cases morse et la tuile morse de la grille affichent la **lettre en cours et son code**, le signe allumé en surbrillance.
- **Contrat d'API 1.5.0** (ajouts seulement) : `light` dans `POST /api/v1/morse`, `settings` sur les cases de vue `morse` / `morse_free`, `morse {playing, text, light, progress}` dans l'événement `state`.

**Modifié**
- Le dépôt GitHub s'appelle désormais **Sokren/sc-telemetry-deck** (les anciens liens redirigent).

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck) et `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
