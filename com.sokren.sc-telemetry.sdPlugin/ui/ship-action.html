Fonctions avec état (train, phares, VTOL, puissance, portes…) : la touche montre l'état réel du vaisseau, « — » hors du vaisseau. Un appui mène à l'état voulu (« Allumer » sur une fonction déjà allumée n'envoie rien). Le titre du Stream Deck remplace le nom affiché ; vide = nom par défaut. Mode, image et alerte sont ignorés pour les commandes simples.
Functions with a state (landing gear, lights, VTOL, power, doors…): the key shows the ship's real state, "—" outside a ship. A press leads to the wanted state ("On" on a function already on sends nothing). The Stream Deck title replaces the displayed name; empty = default name. Mode, image and warning are ignored for single commands.
