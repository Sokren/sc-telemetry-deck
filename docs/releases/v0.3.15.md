**EN — SC Telemetry Deck 0.3.15** — Ready-made views for wide touch screens (Xeneon Edge), a Cockpit look, new item styles and free placement in the web app — plus a fix for the QR code of the Tablet / phone window.

> **Beta** — the telemetry API is new, undocumented by CIG and may change with any patch. **4.10.3 (LIVE) = display only**, **5.0 (PTU) = display + actions**.

**New — web app**
- **View templates**: **＋** offers *Blank* or **Xeneon Edge – pilot** (a pilot station for a wide 2560×720 touch screen). The new view can be edited like any other. Import files are also in `docs/vues/`.
- **One-third** width sections (**−** / **+**: third ↔ half ↔ full) and **tall sections** (↕, two rows: two sections can stack beside it), for wide screens.
- **Cockpit** look: centered clipped-corner buttons, lit in blue; one-line gauges. Self-destruct and eject are always red.
- New item styles: **heading tape** (heading), **switch** (ship functions), **slide** or **hold** to confirm an action — and the **BOOST** light.
- **Free placement**: a dragged item lands in the column where you drop it; the slots before it stay empty (to center a button, leave a gap…). On a phone, items simply follow each other.
- **Line** style for every value (name on the left, value on the right, the height of a bar), e.g. decoys and noise.
- Items as narrow as **1 slot of 16** (every item except warning lights and *My ship*). Width is set with **−** and **+**, with the slots taken shown in between.

**Fixed — web app**
- **Tablet / phone** window: the QR code sometimes stayed a broken image after turning on network access (or changing network card) from the window. It now shows right away, and a failed load is retried.
- Press-and-hold (eject): the progress did not animate (ring on the grid, item filling up in a view).

**API**: contract **1.11.0** — `GET /api/v1/views/templates`, `POST /api/v1/views` with `template`, `third` width, `0.25` size, `tall` section, `cockpit` look, `tape` / `switch` / `slide` / `hold` styles, `col` column, `line` style, `words` on ship functions.

**Stream Deck plugin**: no change besides the version number.

**Downloads**: `com.sokren.sc-telemetry.streamDeckPlugin` (double-click to install or update in Stream Deck), `sc-telemetry-web.exe` (standalone web app — nothing else to install, Node.js is built in) and `sc-telemetry-web-0.3.15-portable.zip` (the same web app for PCs where Smart App Control blocks the exe).

**Setup**: see the README — 4.10.3 LIVE: `setx GRPC_CLIENT_SERVER_ENABLED true`; 5.0 PTU: `server.game.telemetry.enabled=1` in `StarCitizen\PTU\user.cfg`.

🇫🇷 **FR — SC Telemetry Deck 0.3.15** — Des vues toutes prêtes pour les écrans tactiles larges (Xeneon Edge), un habillage Cockpit, de nouveaux styles de case et le placement libre dans l'appli web — plus un correctif pour le QR code de la fenêtre Tablette / téléphone.

> **Bêta** — l'API de télémétrie est récente, non documentée par CIG et peut changer à chaque patch. **4.10.3 (LIVE) = affichage seulement**, **5.0 (PTU) = affichage + actions**.

**Nouveau — appli web**
- **Modèles de vues** : **＋** propose *Vierge* ou **Xeneon Edge – pilote** (poste de pilotage pour écran tactile large 2560×720). La vue créée se modifie comme les autres. Les fichiers à importer sont aussi dans `docs/vues/`.
- Sections en **tiers** de largeur (**−** / **+** : tiers ↔ demie ↔ pleine) et **sections hautes** (↕, sur deux lignes : deux sections peuvent s'empiler à côté), pour les écrans larges.
- Habillage **Cockpit** : boutons centrés à coins coupés, allumés en bleu ; jauges sur une ligne. L'autodestruction et l'éjection sont toujours en rouge.
- Nouveaux styles de case : **règle de cap** (cap), **interrupteur** (fonctions du vaisseau), **glisser** ou **maintenir** pour confirmer une action — et voyant **BOOST**.
- **Placement libre** : une case glissée se pose dans la colonne où on la lâche ; les emplacements d'avant restent vides (pour centrer un bouton, laisser un trou…). Sur téléphone, les cases se suivent.
- Style **Ligne** pour toutes les valeurs (nom à gauche, valeur à droite, hauteur d'une barre), par ex. leurres et bruit.
- Cases d'**1 emplacement sur 16** (toutes sauf voyants et *Mon vaisseau*). La largeur se règle avec **−** et **+**, le nombre d'emplacements pris entre les deux.

**Corrigé — appli web**
- Fenêtre **Tablette / téléphone** : le QR code restait parfois une image cassée après avoir activé l'accès réseau (ou changé de carte réseau) depuis la fenêtre. Il s'affiche maintenant tout de suite, et un échec de chargement est réessayé.
- Appui maintenu (éjection) : la progression ne s'animait pas (anneau de la grille, case qui se remplit dans une vue).

**API** : contrat **1.11.0** — `GET /api/v1/views/templates`, `POST /api/v1/views` avec `template`, largeur `third`, taille `0.25`, section `tall`, habillage `cockpit`, styles `tape` / `switch` / `slide` / `hold`, colonne `col`, style `line`, `words` sur les fonctions du vaisseau.

**Plugin Stream Deck** : aucun changement à part le numéro de version.

**Téléchargements** : `com.sokren.sc-telemetry.streamDeckPlugin` (double-clic pour installer ou mettre à jour dans Stream Deck), `sc-telemetry-web.exe` (appli web autonome — rien d'autre à installer, Node.js est intégré) et `sc-telemetry-web-0.3.15-portable.zip` (la même appli web pour les PC où Smart App Control bloque l'exe).

**Mise en place** : voir le README — 4.10.3 LIVE : `setx GRPC_CLIENT_SERVER_ENABLED true` ; 5.0 PTU : `server.game.telemetry.enabled=1` dans `StarCitizen\PTU\user.cfg`.
